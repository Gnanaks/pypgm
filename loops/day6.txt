5. HAPPY NUMBER:
--  A NUMBER is considered as HAPPY NUMBER only if repeatedly it with sum of the square of the digits which eventually results in 1.
ex: 19 -> 1**2 + 9**2 --> 82
    82 -> 8**2 + 2**2 --> 68
    68 -> 6**2 + 8**2 --> 82

#code 
#happy number
n = int(input("enter the number:"))
while n != 1 and n != 4:
    total = 0
    temp = n

    while temp > 0:
        last_digit = temp % 10 
        total += last_digit * last_digit
        temp //= 10

    n = total
if n == 1:
    print("happy number")
else: 
    print("not happy number")

13. GCD (Greatest common divisor)
-- It is thhe largest number that divides both the given number exactlly .
Ex : 12 and 24 -- GCD is --> 24 
Note : GCD always will be either the lesser value b/w two inputs or less than that .
# code 
a = int(input("Enter the first value : "))
b = int(input("Enter the second value: "))
gcd = 1
limit = a
if b < limit :
    limit = b 
for i in range( 1, limit + 1):
    if a % i == 0 and b % i == 0:
        gcd = 1 
print('gretest Common Divisor=',gcd )

14. LCM(Lowest common multiple)

     Among them 12 is the LCM

#code

b = int(input("Enter the second value: "))

    lcm += a

16.PALLINDROME OF NUMBER:
--The process of reversing the given number and comparing the reversed number with the original number . If it satisfies then it is PALLINDROME

#code
n = int(input("Enter a number: "))

temp = n
reverse = 0

while temp > 0:
    digit = temp % 10
    reverse = reverse * 10 + digit
    temp //=10

if n == reverse:
    print(n, "is a Palindrome Number")
else:
    print(n, "is not a Palindrome Number")

17. DIGIT FREQUENCY:
-- The process of finding how many times each digit(0-9) occurs in a given number .
Ex: 11222333444455
    O/P :{ 1 : 2 , 2 : 3 , 3 : 3 , 4 : 4 , 5 : 2}

#code
n = int(input("Enter the Number: "))
out = {}
for i in range(0, 10):
    temp = n
    count = 0
    while temp > 0:
        last_digit = temp % 10
        if last_digit == i:
            count += 1
        temp //= 10
    if count > 0:
        out[i] = count
print(out)

17.SECOND LARGEST ELEMENT IN A COLLCTION  : 
-- The process of finding  the second largest element in a collection by assuming initial value as the largest at the start .
Ex : [10, 20, 50, 40, 30]

#code
a = [10, 25, 8, 40, 30]
largest = a[0]
second = a[0]
for i in a:
    if i > largest:
        second = largest
        largest = i
    elif i > second and i != largest:
        second = i
print("First largest element:", largest)
print("Second largest element:", second)
